# theokand.github.io

Theo Kandiliotis's public site, served by GitHub Pages at https://theokand.github.io/.

- `index.html`: the profile page.
- `talos24/`: the Talos 24 app's home page (`index.html`) and privacy policy (`privacy.html`), the two pages Google's OAuth consent screen links to.
- `skills/`: agent skills in the open Agent Skills format (agentskills.io), one folder each with its `SKILL.md` and a page (`index.html`), a `.zip` of the folder beside it, and `skills/index.html` listing them.

Another app gets its own folder beside `talos24/`, with the same two pages.
